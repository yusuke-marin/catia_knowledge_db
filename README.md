# CATIA 実務自動化パーフェクトバイブル｜付属AI専用ナレッジデータベース

『現場で使える CATIA 実務自動化パーフェクトバイブル』の購入者特典として提供する、AI専用のナレッジデータベースです。

CATIA V5 VBAオートメーションAPI（全1165クラス）と、EKL（ルール）関連のヘルプ資料を、AIコーディングツール（Claude Code、Codex、Antigravity等）が参照しやすいMarkdown/JSON形式に整理・要約したものです。
