# インストール用バッチファイル

書籍の第1章で紹介しているインストールコマンドを、そのまま実行できる形にしたものです。コマンドを手で打つのが面倒な方は、使いたいAIツールのファイルをダウンロードしてダブルクリックしてください。

- `install_claude_code.cmd` … Claude Code
- `install_codex.cmd` … Codex（ChatGPT）
- `install_antigravity.cmd` … Antigravity（Gemini）

いずれも中身は書籍に載せている公式コマンドそのものです。実行するとコマンドプロンプトの画面が開き、インストールが進みます。
